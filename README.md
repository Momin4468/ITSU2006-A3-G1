# Insight360 Data Analytics Dashboard: Project Plan

Version control repository for the ITSU2006 group project. This repository holds the
project plan, supporting documents and diagrams for the Insight360 Data Analytics
Dashboard for Real-Time Business Insights.

## Project summary

Insight360 is a proposed real-time analytics dashboard for a mid-sized Australian retail
group. The dashboard will consolidate point-of-sale, inventory and web analytics into live
key performance indicators for store and regional managers, so that decisions can be made
on current data rather than on reports that are days old.

## How version control is used

The team uses this repository for configuration management of all project documents. Each
document is kept under version control, changes are recorded in CHANGELOG.md, and material
changes to the baseline follow the change request process described in
docs/change-request-form.md. New or updated files are added through commits with clear
messages so that the history of the plan can be traced.
